# Third-party notices

This project is a Vue 3 adaptation inspired by the open-source
[Sileo](https://github.com/hiaaryan/sileo) project by
[hiaaryan](https://github.com/hiaaryan).

The original project describes itself as an MIT-licensed, physics-based toast
component for React. Its public API, visual approach, CSS data attributes, and
interaction model were used as the reference example for this Vue port.

This repository is an independent adaptation and is not an official release of
the original Sileo project.
